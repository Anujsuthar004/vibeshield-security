Privacy

Privacy posture for a code security platform.

The scanner processes repository source or pasted code only to produce security findings. Raw source files are not retained after scan execution.

Data minimization

The current scanner stores result metadata and redacted findings. It does not store raw repository files after the worker finishes.

Retention

Scan results expire automatically within the configured retention window, capped at 24 hours in this implementation.

Subprocessors

Public deployment uses Vercel hosting and GitHub APIs for repository access. No external model provider is used by the deterministic scanner.

Exports

Findings redact secret-looking values before returning evidence to the browser.
