Privacy

Privacy posture for a code security platform.

This static site does not collect form submissions. Production repository scanning should collect only what is necessary to run scans and produce reports.

Data minimization

Keep repository metadata, scan findings, and billing records separate. Avoid storing full source unless retention is explicitly enabled.

Retention

Default source retention should be short, visible, and configurable. Customers should be able to delete scan artifacts.

Subprocessors

Any external model, hosting, logging, or payment vendor should be listed with the data categories they process.

Exports

Reports should omit raw secrets and sensitive snippets unless the customer explicitly chooses an evidence-rich export.
