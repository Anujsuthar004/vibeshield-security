Security

How VibeShield handles customer source code.

This page describes the operating posture today. Items marked roadmap are commitments, not certifications.

Repository access

Private repository scans require the VibeShield GitHub App with read-only repository contents permission. Patch generation uses contents:write only on a branch named vibeshield/fixes-* — never the default branch — and never amends customer commits.

Worker isolation

Each scan runs in a single-use temporary directory. The worker is wiped at the end of the scan, and a background reaper deletes any directory idle for more than an hour. Raw source files are not retained.

Secret handling

Secret-like strings (API keys, tokens, JWTs, AWS access keys, Slack tokens, OpenAI/Stripe keys) are detected and masked before findings are persisted. Stored evidence contains the redaction marker rather than the original value.

Auth

Passwords are bcrypt-hashed (cost 10). Sessions are HttpOnly, Secure, SameSite=Lax with a 14-day TTL. API keys are stored as SHA-256 hashes with a non-secret prefix shown in the dashboard. Webhooks must be signed with X-Hub-Signature-256 and the configured webhook secret.

Headers

Edge responses set Content-Security-Policy, X-Content-Type-Options, Referrer-Policy, and Permissions-Policy. The CSP forbids inline scripts, third-party origins, and framing.

Disclosure

Report security issues to security@vibeshield.example. Encrypt with our PGP key on request. We commit to acknowledging reports within 2 business days and remediating critical issues within 14 days.

Compliance roadmap

We do not hold SOC 2 or ISO 27001 today. A SOC 2 Type I engagement is scoped for late 2026 if customer demand justifies the audit cost. Until that engagement is contracted, no compliance certification is claimed.

Deletion

Workspace owners can delete individual scans, revoke API keys, and request full workspace deletion via the privacy contact. Deletion completes within 30 days and is logged in the audit trail.
