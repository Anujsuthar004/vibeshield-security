Security

How VibeShield should handle customer source code.

This public build is a static product site and local demo. A production implementation should use these controls before accepting real repositories.

Repository access

Use a GitHub App with read-only repository permissions by default. Write permissions should be requested only for explicit patch workflows.

Isolation

Run every scan in an ephemeral worker with no shared filesystem between tenants. Remove source after the retention window or on customer request.

Secrets

Detect and redact credentials before evidence storage or model analysis. Store fingerprints and locations, never raw secret values.

Auditability

Log repository connections, scan starts, exports, patch creation, and user access changes in a customer-visible audit trail.
