Security

How VibeShield should handle customer source code.

This public build includes a deterministic backend scanner. Private repository scanning requires the GitHub App environment variables described in the setup guide.

Repository access

Use a GitHub App with read-only repository permissions by default. Write permissions should be requested only for explicit patch workflows.

Isolation

Each scan uses a dedicated temporary worker directory that is removed after scan completion. Scan results expire after the configured retention window.

Secrets

Secret-looking values are redacted in returned evidence. The scanner stores findings, metadata, and fingerprints rather than raw source files.

Deletion

Scan results can be deleted through the scan result API before the retention window expires.
